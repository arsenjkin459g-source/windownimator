# 🎬 Windownimator 2.0 (PySide6 Edition)

**Windownimator 2.0** — уникальный аниматор для Windows, позволяющий создавать анимационные ролики из настоящих системных окон Windows (`MessageBoxW`). 

Окна плавно перемещаются по экрану по ключевым кадрам с использованием функций сглаживания (easing), воспроизводят звуки и экспортируются в автономные `.exe` файлы.

---

## 🌟 Основные возможности

- 🪟 **Нативные окна Windows:** Анимация строится на базе настоящих диалогов WinAPI (`MessageBoxW`, `SetWindowPos`), а не просто эмуляций.
- 🎨 **Современный Qt6 интерфейс (PySide6):**
  - Интерактивный канвас виртуального экрана 1920x1080 с перетаскиванием окон мышкой.
  - Удобный таймлайн ключевых кадров.
  - Живой анимированный график кривых движения (Easing Preview).
- 📈 **Плавные функции движения (Easing):**
  - Linear, Ease In, Ease Out, Ease In-Out, Bounce (пружина), Elastic (упругость).
- 🔊 **Звуковое сопровождение:**
  - Поддержка системных звуков Windows и пользовательских аудиофайлов (`.wav`, `.mp3`, `.ogg`).
  - Выбор конкретного кадра для запуска звука.
- 📦 **Экспорт в автономный `.exe`:**
  - Возможность скомпилировать созданную анимацию в независимый исполняемый файл Windows без необходимости установки Python.
- 💾 **Формат проектов `.wa`:**
  - Сохранение и загрузка проектов для продолжения редактирования в любой момент.

---

## 🛠 Технологический стек

- **Python 3.14+**
- **PySide6 (Qt 6)** — интерфейс пользователя
- **WinAPI (`ctypes`)** — управление нативными окнами Windows
- **PyInstaller** — сборка автономных `.exe` файлов
- **Pygame / Winsound** — звуковой движок

## 🚀 Запуск проекта

```bash
# Клонирование репозитория
git clone https://github.com/arsenjkin459g-source/windownimator.git
cd windownimator

# Установка зависимостей
pip install PySide6 pygame-ce pyinstaller

# Запуск редактора

```
